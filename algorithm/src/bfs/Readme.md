BFS（Breadth-First Search，广度优先搜索）经典例题‌包括以下几种类型：
1.	单词梯子‌：给定两个单词（起始单词和目标单词）以及一个字典，找出一条从起始单词变换到目标单词的最短路径，每次变换只能改变一个字母，并且变换过程中的每个单词都必须在字典中‌。
2.	‌迷宫最短路径‌：给定一个迷宫和一个起点及终点，找到从起点到终点的最短路径‌。
3.	‌二叉树层序遍历‌：给定一个二叉树，按层序遍历输出其节点值‌。
4.	‌图的最短路径‌：给定一个无向图和一个起点，找到从起点到所有其他顶点的最短路径‌。
5.	‌开启所有房间的钥匙‌：有一些房间，每个房间里有不同数量的钥匙，每把钥匙可以打开另一个房间的门。最初你在0号房间，你要收集所有房间的钥匙，问最少需要进入多少个房间‌。
6.	‌矩阵中的最短路径‌：给定一个由0和1组成的矩阵，其中1代表墙壁，0代表可走的路。你从左上角(0,0)出发，要走到右下角(n-1,m-1)，每次只能向右或向下移动一步，求最短路径长度‌。
7.	‌机器人行走的最短路径‌：有一个m x n的网格，机器人从左上角开始，只能向右或向下移动，要到达右下角。网格中有一些障碍物，机器人不能进入。求机器人到达右下角的最短路径长度‌。
8.	‌最短回文串‌：给定一个字符串，你可以通过添加字符将其变成回文串。求需要添加的最少字符数‌。
9.	‌迷宫中离入口最近的出口‌：在迷宫中找到离入口最近的出口‌。
10.	‌最小基因变化‌：给定一个基因序列，通过一系列变化将其变为目标序列，求最少的变化次数‌。
11.	‌单词接龙‌：给定一组单词和起始单词，通过添加或删除字母将起始单词变为目标单词，求最短的变换序列‌。
12.	‌砍树‌：给定一个森林，通过砍树来减少树木数量，使得从起点到终点的最短路径长度最小化‌。
